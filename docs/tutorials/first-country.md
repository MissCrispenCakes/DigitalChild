# Explore your first country assessment

This tutorial takes you through one assessment so you can distinguish a score, its evidence, and a documentation gap. You need a browser; no installation or account is required.

## 1. Open the explorer

Open the [country evidence explorer](../scorecard/explorer.md). Wait for the country table, then enter **Canada** in “Search country”. You should see one matching country. The number above the table tells you how many results match.

## 2. Read the summary

Read Canada's Protection Score, Risk Index, and Doc count. Protection ranges from 0 to 20, Risk from 0 to 100, and Doc counts documented justifications out of ten. The indicator definitions explain how those values are calculated.

## 3. Open the assessment

Activate the **Canada** button in the first column, using a click or the keyboard. A detail panel opens and receives focus. Read one indicator's score, scoring rule, written assessment, and source link.

If an indicator has no written assessment, the panel says so. A missing justification is a reason to investigate, even when a numerical score exists.

## 4. Check the source and date

Follow one source link when you are ready to leave GRIMdata. Compare the document's date and scope with the written assessment. The explorer's metadata distinguishes when this snapshot was generated from its source-verification stamp. Compare these dates with any later policy changes relevant to your question.

## 5. Return to the whole dataset

Close the country panel and select **Reset**. All 194 country rows return. Try “Only fully documented” to see the subset with ten documented justifications; this snapshot has 132.

You have now read a score in context. Continue with the [methodology](../scorecard/design.md) to understand the rubric, or [download the snapshot](../scorecard/data-access.md#published-snapshot-downloads) to work with it yourself.
